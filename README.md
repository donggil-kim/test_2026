# 통합 클라우드 보안위협 매트릭스

MITRE ATT&CK Cloud 킬체인을 뼈대로 AWS·Azure·Kubernetes 벤더 위협 매트릭스, CSA Top
Threats to Cloud Computing 2026, 클라우드 보안사고 사례 DB(680건)를 하나로 통합한
위협 매트릭스입니다. 이전에 구축한 **통합 AI 보안위협 매트릭스 v3.2**의 구조(3계층
분류 → 위험평가 → 실제근거)와 산정 로직을 클라우드 보안에 이식했습니다.

## 산출물

| `output/threat_text_template.csv` | 세부위협명·요약설명·참조·탐지대응 문구 입력용 템플릿 |

| `docs/methodology.md` | 방법론·매핑 규칙 상세 |

### v5 변경 사항

1. **발생가능성 기준을 AI 매트릭스 v3.2 수식과 통일**: 상 = 실제 사고 2건 이상(ATT&CK 사례는 건수와 무관하게 '중'까지).
   v4의 '실제 사고 ≥3건 또는 ATT&CK 사례 ≥10건'은 AI 매트릭스와 기준값이 달랐음. 11개 행(고유 기법 8개)의 발생가능성·위험도 변경
   — 위험도 분포 매우 높음 17→16 · 높음 56→60 · 보통 64→60 · 낮음 17→18 (근거 대응표는 `docs/methodology.md` §6)
2. **CSA SI-06(AI 시스템 침해) 연계 재검토**: v4는 T1496 자원 악용 전체를 SI-06에 연계해 크립토재킹 사고 127건이 'AI 시스템 침해'로
   집계됐음. SI-06은 LLMjacking을 다루는 T1496.004에만 남기고(SI-01 · SI-06), SMS 펌핑(T1496.003)은 SI-04, 상위기법·컴퓨트·대역폭 변형은
   다른 영향 기법처럼 미연계. `CSA 2026 연계` 시트에 '연계 기준' 열(SI-02·SI-06·SI-08 사유)과 '그중 실제 사고' 열 추가
   (기존 '연계 실제 사고 수'는 연구·노출 사례까지 센 값이었음). 위험평가 값은 변경 없음 (`docs/methodology.md` §4)

### v4 변경 사항

- 설명을 **클라우드 특화 관점으로 재작성**: 기존 번역문의 첫 문장을 그대로 쓰지 않고, ATT&CK 원문·벤더 매트릭스·사고 DB·CSA Top Threats 2026을 분석해 다시 요약·구조화
  - **요약설명**: 2줄 개조식(①위협 메커니즘 ②클라우드 발생 조건·영향·탐지 곤란 사유), 명사형 종결 — AI 매트릭스 v3.2의 Lv3 설명 형식과 통일
  - **참조**: `■ 클라우드 관점`(대상 서비스·API·벤더 기법 ID·통합 범위) · `■ 실제 사례`(사고 DB·ATT&CK·CSA 2026 사례, 출처 표기)로 재구성
- **탐지·대응 포인트 열 신설**: 세부위협별 탐지 단서와 대응 방안을 별도 열(`■ 탐지` / `■ 대응`)로 추가 — 통합 매트릭스·LITE 모두 반영
- 문구 입력 통로 확장: `data/threat_text_override.csv`에 `탐지·대응(입력)` 열 추가. 분류체계·위험평가·근거 집계 로직은 v3와 동일(변경 열은 요약설명·참조·설명 출처·탐지대응뿐)
- 적용 범위: 고유 기법 **126개 전체**(세부위협 154행)를 클라우드 관점으로 재작성 완료. 모든 행의 '설명 출처'가 '사용자 입력'

### v3 변경 사항

- 세부위협 열 구조: **세부위협(Lv3) → 요약설명 → 참조**. 참조에는 ATT&CK 원문 보충 목록 · 실제 사례(사고 DB) · ATT&CK 사례 · 통합된 기법을 구분해 정리
- 설명이 '…다음과 같은 것들이 있다:'에서 끊기던 문제 수정: 원본 요약이 ATT&CK 설명 첫 문단만 번역해 콜론 뒤 목록이 빠졌던 것이 원인. ATT&CK 원문에서 목록을 복원해 참조 열에 넣고, 빌드 시 ':'로 끝나는 요약을 검사
- 클라우드 특화 검토: 클라우드 맥락이 없는 일반 엔터프라이즈 기법 11개 삭제, 31개 통합(근거·벤더 항목은 대상 행에 합산). 클라우드 전용·M365/Office·K8s/컨테이너 항목은 유지 (206 → 154행, 사고 근거 손실 0건)
- 문구 입력 통로: `data/threat_text_override.csv`(템플릿 `output/threat_text_template.csv`)에 작성한 세부위협명·요약설명·참조를 빌드 시 우선 적용

### 워크북 시트

- **개요** — 기준 데이터, 분류체계, 결과 요약, 주의사항
- **매트릭스 뷰** — 전술(열)별 세부위협을 위험도 색으로 배치한 한눈 보기
- **통합 매트릭스** — 분류체계 · 교차매핑 · 위험평가 · 실제근거 · 탐지·대응 전체(위협 설명·심각도 근거 포함)
- **통합매트릭스_LITE** — 핵심 열 발췌 + 탐지·대응 포인트
- **도메인 요약** — 전술별 위험도·근거수준 분포, 매핑 사고 수, 최고위험 항목
- **CSA 2026 연계** — 11대 위협별 연계 세부위협·사고 수(실제 사고 구분)와 연계 기준
- **역매핑_사고사례** — 사고 680건과 매핑 기법(근거 추적용)
- **평가 기준** — 산정 규칙

### v2 변경 사항

- 상위기법에 달린 근거(사고 태그·ATT&CK 사례·벤더 항목)가 누락되던 문제 수정 → `.0 (일반·상위기법)` 행으로 보존
  (사고 매핑 반영 118건 → 245건, 세부위협 169 → 206행)
- 실제 사고와 연구·노출 사례 분리 집계, 최근(2025~) 사고 수 추가
- '비클라우드 의심' 사고 집계 제외, 폐기 ATT&CK ID(T1562 등) v19.2로 변환
- 위협 설명·심각도 근거·AI 매트릭스 연계(UT) 열 추가
- 발생가능성 규칙을 AI 매트릭스 v3.2와 통일(코드·문서 일치)
- 매트릭스 뷰·도메인 요약·CSA 2026 연계 시트 추가

## 분류 체계 (ATT&CK 킬체인 기준)

- **Lv1 도메인** = ATT&CK 전술 14개 (`[IA] 초기 침투` … `[IM] 영향`)
- **Lv2 위협분류** = ATT&CK 기법 (`CTC-IA-02` = T1190)
- **Lv3 세부위협** = 하위기법 또는 벤더 특화 항목 (`CTC-IA-07.3` = T1078.004). `.0 (일반·상위기법)`은 하위기법으로 특정되지 않은 상위기법 근거

각 세부위협에 **교차매핑**(ATT&CK ID · AWS TTC · Azure ATRM · K8s · CSA Top Threats
2026 연계), **위험평가**(발생가능성×심각도→위험도), **실제근거**(ATT&CK 클라우드 사례 수
· 사고DB 사례 수 · 근거수준 · 관련 사고 ID · 대표 사례), **탐지·대응 포인트**가 붙습니다.
