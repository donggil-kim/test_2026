## 요약

- 후보 총 35건 — 추가 제안 28 · 관찰 4 · 기존 보강 3 · 제외 0

- AI 활용(제외 뺀 35건): 확인 7 · 추정 3 · 없음 25

- 중복 확인: 통합 목록 913행 + 원본 DB 5종(공급망·신원·물리·OT YAML, 클라우드 xlsx 680건) + `incident_aliases.yaml`을 조직·사건 키워드 정규식으로 대조했습니다(표기가 다른 같은 사건은 놓칠 수 있음).
- 제안 원본 DB는 공격 경로 기준(F10): 웹·클라우드 침해→클라우드 DB, 계정·사칭·비싱·딥페이크 본인확인→신원 DB, 소프트웨어 공급망→공급망 DB, 설비·운영 중단→OT DB, 내부자·물리→물리·인적 DB.
